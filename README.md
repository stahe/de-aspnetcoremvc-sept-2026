# Schritt-für-Schritt-Einführung in das ASP.NET Core MVC Framework

**Der Kurs ist hier online verfügbar: [https://stahe.github.io/de-aspnetcoremvc-sept-2026/](https://stahe.github.io/de-aspnetcoremvc-sept-2026/)**

## Überblick

Dieser Kurs führt Schritt für Schritt durch die Erstellung einer MVC-Webanwendung mit **ASP.NET Core MVC** (.NET 10, C#). Die HTML-Seiten werden vom Server mit **Razor**-Views erzeugt, ohne ein JavaScript-Framework im Browser.

Er folgt auf den Kurs *Schritt-für-Schritt-Einführung in das Web-Framework NestJS* (2026) und hat genau denselben Aufbau:

1. **28 kurze Beispiele**, die sich jeweils auf ein bestimmtes Konzept konzentrieren:
   - Controller, Actions und Routing;
   - Action-Modell: Parameterbindung, Konvertierung und Validierung;
   - Razor-Views: Templates, Partial Views, Helper und Tag Helper;
   - Formulare, Validierung und das Post/Redirect/Get-Muster (TempData);
   - Internationalisierung (Französisch/Englisch);
   - Datenbereiche: Singleton, Scoped und Transient; Cookies;
   - Lebenszyklus einer Anfrage: Middleware, Filter, Fehlerseiten;
   - Authentifizierung über ein JWT-Token in einem Cookie, Rollen, CAPTCHA und Ratenbegrenzung;
   - Schichtenarchitektur (Web / Geschäftslogik / DAO) mit **Entity Framework Core** und **MySQL**.
2. **Eine umfassende Fallstudie**, *RdvMedecins*: eine Anwendung zur Terminplanung für eine Arztpraxis mit drei Rollen (Administrator, Ärzte, Patienten). Der Kurs erläutert jede ihrer Dateien im Detail.

Die Leser benötigen keinerlei Vorkenntnisse in ASP.NET Core: Jedes Beispiel ist Zeile für Zeile kommentiert, und der Kurs gibt für jedes die genaue URL zum Testen an.
